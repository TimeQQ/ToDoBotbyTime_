Telegram ToDo-бот с планировщиком задач
Простой и удобный Telegram-бот для управления задачами. Позволяет добавлять задачи с дедлайном через интерактивный календарь, просматривать задачи на сегодня или все сразу, отмечать их выполненными и получать напоминания о просроченных задачах.

Возможности
Добавление задач с названием и дедлайном:

Удобный inline-календарь для выбора даты.

Выбор часа и минут кнопками (шаг 15 минут).

Просмотр задач:

Список всех задач с номерами и статусом (выполнено / в работе).

Фильтр "на сегодня".

Завершение задач по номеру.

Автоматические напоминания:

Бот каждую минуту проверяет наступившие дедлайны и отправляет уведомление.

Отмена операции на любом этапе добавления.

Технологический стек
Python 3.10+

aiogram 3.x — фреймворк для Telegram Bot API

aiogram-calendar — интерактивный календарь

APScheduler — планировщик напоминаний

SQLite — лёгкая встроенная база данных

Установка и запуск
1. Клонирование репозитория

git clone https://github.com/yourusername/todo-telegram-bot.git
cd todo-telegram-bot
2. Создание виртуального окружения (рекомендуется)

python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate         # Windows
3. Установка зависимостей

pip install -r requirements.txt
4. Настройка переменных окружения
Создайте файл .env в корне проекта и добавьте токен вашего бота:


BOT_TOKEN=ВАШ_ТОКЕН_БОТА
Получить токен можно у @BotFather в Telegram.

5. Запуск бота
bash
python main.py
Использование
Команды и кнопки
Кнопка				Действие
Добавить задачу			Начать создание новой задачи
Задачи на сегодня		Показать задачи с дедлайном сегодня
Все задачи			Показать все задачи пользователя
Завершить задачу		Отметить задачу выполненной (введите номер)
Отмена				Прервать текущую операцию

Пример диалога добавления задачи
Нажимаете Добавить задачу.

Вводите название (например, Купить продукты).

Выбираете дату в календаре.

Выбираете час и минуты.

Бот сохраняет задачу и подтверждает добавление.

Напоминания
Если задача не выполнена к моменту дедлайна, бот пришлёт сообщение:


Напоминание!
Задача *Купить продукты*
Дедлайн истёк: 2026-03-10 18:00
